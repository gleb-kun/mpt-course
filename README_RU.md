# mpt-course

Материалы для курсов, которые посвящены компьютерным технологиям для математических исследований и математическим основам информатики.

Репозиторий содержит материалы, задачи, шаблоны и прочую документацию для работы с Python, Maple, LaTeX а также Ops-инструментам. Структура проекта организована по типам задач и используемым инструментам.

Большинство материалов представлены на двух языках, см. файлы README:
- [Русский](README_RU.md),
- [Английский](README.md).

## Назначение

- `common/` — материалы общего характера.
- `latex/` — материалы для практических работ с использованием LaTeX.
- `maple/` — практикумы и лабораторные по системе Maple.
- `ops/` — материалы, посвященные таким инструментами, как Docker, .git.
- `python/` — практикумы и лабораторные с использованием языка Python и среды JupyterLab.
